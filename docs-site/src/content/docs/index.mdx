## Install

On any Linux server with Docker and a domain pointing at it – one command, automatic HTTPS:

<div class="hl-install">

```bash title="Install HyperLevel"
curl -fsSL https://raw.githubusercontent.com/BAISESYSTEMS/GoHyperLevel/main/scripts/install.sh | bash
```

</div>

<Tabs>
	<TabItem label="Docker Compose">
		```bash
		git clone https://github.com/BAISESYSTEMS/GoHyperLevel.git hyperlevel && cd hyperlevel
		cp .env.example .env                    # set PGHL_BASE_URL and PGHL_DOMAIN
		docker compose --profile caddy up -d    # HyperLevel + Caddy (Let's Encrypt)
		```
	</TabItem>
	<TabItem label="Local demo">
		```bash
		npm ci && npm run build
		npm run demo:seed -- --data-dir ./demo-data
		PGHL_DATA_DIR=./demo-data npm start     # http://localhost:4700 · demo@example.com / demo1234
		```
	</TabItem>
	<TabItem label="Connect your agent">
		```bash
		# Claude Code – every HyperLevel tool in your terminal
		claude mcp add --transport http hyperlevel https://<your-domain>/mcp --header "Authorization: Bearer pghl_…"
		```
	</TabItem>
</Tabs>

More ways – Hostinger, Coolify, Railway, Render, plain Node.js: [Deploy options](/deploy/).
