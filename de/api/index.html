API

Dieser Inhalt ist noch nicht in deiner Sprache verfügbar.

Base: https://<your-domain>. Create keys under Settings → API & webhooks; each key belongs to one sub-account.

Machine-readable: OpenAPI 3.1 at GET /api/openapi.json, as a web page at GET /api/docs.html (both without a key). REST hooks, Zapier/Make/n8n, “Webhook received” and the HubSpot import: docs/integrations.md.
