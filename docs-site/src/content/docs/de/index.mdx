## Installieren

Auf jedem Linux-Server mit Docker und einer Domain, die auf ihn zeigt – ein Befehl, HTTPS automatisch:

<div class="hl-install">

```bash title="HyperLevel installieren"
curl -fsSL https://raw.githubusercontent.com/BAISESYSTEMS/GoHyperLevel/main/scripts/install.sh | bash
```

</div>

<Tabs>
	<TabItem label="Docker Compose">
		```bash
		git clone https://github.com/BAISESYSTEMS/GoHyperLevel.git hyperlevel && cd hyperlevel
		cp .env.example .env                    # PGHL_BASE_URL und PGHL_DOMAIN setzen
		docker compose --profile caddy up -d    # HyperLevel + Caddy (Let's Encrypt)
		```
	</TabItem>
	<TabItem label="Lokale Demo">
		```bash
		npm ci && npm run build
		npm run demo:seed -- --data-dir ./demo-data
		PGHL_DATA_DIR=./demo-data npm start     # http://localhost:4700 · demo@example.com / demo1234
		```
	</TabItem>
	<TabItem label="Agent verbinden">
		```bash
		# Claude Code – alle HyperLevel-Tools im Terminal
		claude mcp add --transport http hyperlevel https://<deine-domain>/mcp --header "Authorization: Bearer pghl_…"
		```
	</TabItem>
</Tabs>
